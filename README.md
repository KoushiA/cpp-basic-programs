# Basic C++ Programs

This repository contains beginner-friendly C++ programs that focus on fundamental programming concepts such as loops, conditionals, recursion, functions, and number logic.

## 📘 Topics Covered
- ✔ Conditional statements (if/else)
- ✔ Loops (for, while)
- ✔ Number logic programs
- ✔ Recursion
- ✔ Functions
- ✔ Basic mathematics in programming

## 📂 Programs Included
- Print natural numbers  
- Even/Odd number check  
- Factorial of a number  
- Fibonacci series  
- Prime number check  
- Largest of three numbers  
- Reverse a number  
- Multiplication table  
- Vowel or consonant checker  

## 🛠 Language Used
- **C++**

## 🎯 Purpose
These programs help build strong fundamentals in C++ and prepare for:
- Data Structures & Algorithms  
- Competitive programming  
- Technical interviews  
- Academic exams
